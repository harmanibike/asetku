# Asetku

Aplikasi Android Flutter untuk melacak investasi dan seluruh kekayaan pribadi.

## Fitur fondasi saat ini
- Dashboard rancangan awal.
- Tema modern Material 3.
- Database SQLite lokal dengan tabel assets, transactions, dan price_history.
- Model aset dan transaksi dasar.
- Format mata uang Rupiah.

## Menjalankan proyek
1. Ekstrak folder proyek.
2. Pastikan Flutter SDK dan Android SDK sudah terpasang.
3. Jalankan `flutter pub get`.
4. Jalankan `flutter run`.

## Catatan
Angka pada dashboard saat ini adalah data ilustrasi antarmuka, bukan portofolio sungguhan.
Database sudah disiapkan, tetapi layar CRUD dan perhitungan portofolio akan dibangun pada tahap berikutnya.

## Identitas Android
Gunakan applicationId dan namespace `com.asetku.app` pada konfigurasi Android.
